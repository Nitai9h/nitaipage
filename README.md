## 本地开发

> 项目自 v3.0.0 迁移至 Vue 3，不再需要 http-server

```shell
# 安装 node（这里不再过多赘述）

node -v

# 进入文件夹（更换 /nitaipage 为你自己的路径）

cd /nitaipage

# 安装依赖

npm install

# 启动开发服务器（默认 http://localhost:11123，默认已开启局域网访问）

npm run dev

```

## 构建与预览

```shell
# 构建产物

npm run build

# 本地预览

npm run preview
```
